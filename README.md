# Amazon Product Scraper

A Python-based Amazon web scraper built using Playwright.

## Features

- Scrapes Amazon product information
- Uses Playwright for browser automation
- Extracts product details dynamically
- Exports scraped data to Excel
- Supports asynchronous scraping

## Tech Stack

- Python
- Playwright
- Pandas
- Asyncio
- Excel

## Installation

```bash
pip install playwright pandas openpyxl
playwright install
